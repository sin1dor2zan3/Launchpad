# Ages \& Stages

## Bad Ideas Studios

#### Launchpad Project ReadMe v1.0



GitHub Link - https://github.com/sin1dor2zan3/Launchpad



### Instructions:



* Collect all of the items necessary to complete each level. Be careful, as you have limited space to carry stuff!



### Controls:



**PLAYER:**



WASD / LStick - Move



E / A - Interact



TAB / X - Toggle Inventory



ESC / START - Pause



**OBJECT MOVEMENT:**



SPACE / RTrigger - Pick Up / Put Down Object



Arrow Keys / D-Pad - Rotate Object



**INVENTORY:**



WASD / LStick - Change Slot



Q / Y - Rotate Item



SPACE / RTrigger - Place Item



R / B - Drop Item



### Key Mechanics:



* Moving and rotating objects to solve puzzles using arrow keys.
* Fitting key items in your limited inventory.
